THIYASH BATMAN-INSPIRED FIRST BIRTHDAY INVITATION

How to open:
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension if you have it.
4. Right-click index.html and choose “Open with Live Server”.
5. The invitation opens in your browser.

You can also double-click index.html to open it directly. The local baby photo is already included at:
assets/thiyash-baby.png

Controls:
- NEXT / PREV: move between scenes
- Dots: jump to a scene
- ↻: replay from the beginning
- 🔊 / 🔇: mute or unmute the browser-generated cinematic cue sounds
- Keyboard: Arrow keys, R to replay, M to mute/unmute

No viewer upload, form, installation, framework, or birthday-detail entry is required.
